Clipper

Clipper is a personal tool to create short vertical clips from your own videos and publish them to your own TikTok account.

What is Clipper?

Clipper is a personal tool that runs on the user's own computer. It helps its owner cut clips from videos, render them in vertical format with subtitles, and publish them to the owner's own TikTok account using TikTok Login Kit and the Content Posting API.

Clipper is not a public service: this website has no user accounts, no database, no analytics and no cookies. It only hosts the legal documents below.
