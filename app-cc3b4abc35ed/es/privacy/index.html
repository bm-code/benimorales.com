Política de privacidad

Última actualización: 2026-11-01

Esta política explica qué datos trata Clipper. Clipper es una herramienta personal que se ejecuta en local en el equipo del usuario; este sitio web solo aloja estos documentos.

1. Este sitio web

Este sitio es estático. No tiene cuentas de usuario, base de datos, analíticas ni publicidad, y no establece cookies. Como cualquier servidor web, la plataforma de alojamiento puede conservar registros técnicos estándar (como la dirección IP y la URL solicitada) por motivos de operación y seguridad; no los usamos para nada más.

2. Cómo trata la aplicación tus datos

Clipper se ejecuta en el propio equipo del usuario. Los archivos de vídeo se leen, cortan, transcriben y renderizan en local; no se suben a ningún servidor operado por nosotros.

3. TikTok Login Kit y Content Posting API

Clipper usa TikTok Login Kit y la Content Posting API para publicar en tu propia cuenta de TikTok. Solicita estos permisos (scopes):

  • user.info.basic: para identificar la cuenta conectada (por ejemplo, nombre visible y avatar) dentro de la aplicación.
  • video.upload: para enviar un vídeo a TikTok.
  • video.publish: para publicar el vídeo en tu cuenta.

4. Tokens de acceso

Los tokens de acceso y de actualización emitidos por TikTok se almacenan cifrados en el propio equipo del usuario y se usan solo para llamar a TikTok en tu nombre cuando se lo pides a la aplicación. No se envían a nosotros ni a ningún otro tercero.

5. Datos que salen de tu equipo

Aparte de esto, ningún dato sale de tu equipo.

  • Los vídeos que decides publicar, que se envían a TikTok junto con el texto y los ajustes que elijas.
  • Opcionalmente, si activas la función: el texto de las transcripciones, enviado a un proveedor de IA que configures para sugerir fragmentos y textos. Si no la activas, no se envía texto de transcripciones.

6. Sin venta ni cesión

No vendemos tus datos ni los compartimos con terceros, salvo los envíos que tú inicias descritos arriba (TikTok y, si se activa, el proveedor de IA elegido). Esos servicios tratan los datos según sus propias políticas de privacidad.

7. Revocar el acceso

  • En TikTok: Ajustes → Seguridad y permisos → Aplicaciones (o «Gestionar permisos de aplicaciones»), busca Clipper y elimínala.
  • En Clipper: desconecta la cuenta de TikTok desde la aplicación, lo que elimina los tokens almacenados en tu equipo.

8. Tus derechos

Como tus datos se almacenan en tu propio equipo, los controlas y puedes borrarlos en cualquier momento. Según dónde vivas, puedes tener derechos sobre tus datos personales (acceso, rectificación, supresión, oposición). Para cualquier asunto relacionado con este sitio o esta política, contáctanos y responderemos con la mayor diligencia posible. Los datos que conserven TikTok o tu proveedor de IA se gestionan a través de esos servicios.

9. Menores

Clipper no está dirigido a menores y debes cumplir los requisitos de edad mínima de TikTok para conectar una cuenta.

10. Cambios

Podemos actualizar esta política. La fecha de «Última actualización» indica la revisión más reciente.

11. Contacto

Puedes contactarnos en i.benimorales@gmail.com.

Clipper es un proyecto personal independiente y no está afiliado ni respaldado por TikTok.
